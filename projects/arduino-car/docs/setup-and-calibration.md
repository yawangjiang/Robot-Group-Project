# 寻光小车接线与标定

本文对应[寻光草图](../firmware/light_seeking/light_seeking.ino)的原始引脚与默认参数。左右均以小车前进方向为准。

## 接线表

| Arduino UNO | 连接目标 | 程序变量 |
| --- | --- | --- |
| A0 | 右侧 LDR 分压中点 | `sensR` |
| A1 | 左侧 LDR 分压中点 | `sensL` |
| D9（PWM） | L298N ENA，逻辑左轮通道 | `enA` |
| D10（PWM） | L298N ENB，逻辑右轮通道 | `enB` |
| D6 | L298N IN1 | `in1` |
| D7 | L298N IN2 | `in2` |
| D4 | L298N IN3 | `in3` |
| D5 | L298N IN4 | `in4` |
| 5V | 两路分压电路上端 | 电源 |
| GND | 两路分压地、驱动逻辑地与电源地 | 共地 |

L298N 通道 A 的电机输出接逻辑左轮，通道 B 接逻辑右轮。程序中两个通道都使用 `INx=HIGH、INy=LOW`；由于电机可能镜像安装，实车前进方向必须实际确认。

电机由匹配电机与驱动模块的电源供电，不从 UNO 的 I/O 引脚供电。模块上的电机电源端、5V 稳压跳线和逻辑电源用法应按实际模块标识确认，报告未给出足够信息来指定电池电压与稳压跳线位置。

ENA/ENB 应接受 D9/D10 的 PWM；若模块用跳线将使能端固定拉高，需要移除对应跳线，不能一边接 PWM、一边用跳线强制拉高。逻辑连接依据参见 [L298 数据手册](https://www.st.com/resource/en/datasheet/l298.pdf)，具体端子以模块为准。

两路 LDR 均采用相同阻值的固定电阻与同一种分压方向。[分压示意](light-seeking-theory.md#光敏电阻与分压采样)提供了一种符合程序极性的接法；报告没有确定当前寻光实物的最终固定电阻值，不能只凭照片指定阻值。

## 编译与上传

使用 Arduino IDE 打开 `firmware/light_seeking/light_seeking.ino`，选择 Arduino UNO 和对应串口后编译、上传。程序只依赖 Arduino 核心，无需安装额外传感器库。

如果已经安装 Arduino CLI 与 AVR 平台，也可以在本项目目录执行：

```sh
arduino-cli compile --fqbn arduino:avr:uno --build-path .arduino-build firmware/light_seeking
arduino-cli upload --fqbn arduino:avr:uno --port <实际串口> --input-dir .arduino-build
```

`<实际串口>` 替换为设备实际端口。本次整理环境未安装 Arduino CLI，以上命令未执行。

## 第一步 确认传感器方向

先将车轮悬空，打开 9600 baud 串口监视器。程序上电后立即运行，没有启动按钮或等待指令。

正常控制时输出类似：

```text
R:503 | L:500 | diff:0
```

分别照亮和遮挡两个传感器，确认：

1. 照亮右侧时，`R` 减小；照亮左侧时，`L` 减小。
2. 遮挡时对应读数增大。
3. A0 对应物理右侧、A1 对应物理左侧。

若越亮读数越大，先调整分压接法；交换两路输入只会改变左右关系，无法修正明暗极性。

## 第二步 确认电机方向与左右通道

将光源放在正前方，观察两个车轮是否都朝小车前进方向转动。若单个电机反转，断电后调整该电机接线，使其与程序的 `HIGH/LOW` 前进定义一致。

将光源移向左侧，应该看到左轮 PWM 降低；移向右侧，应该看到右轮 PWM 降低。如果串口差值正确但转向相反，检查电机左右通道。

## 第三步 标定传感器补偿 L

让左右 LDR 处于尽量一致、稳定的照明条件，记录多组原始读数。根据公式：

$$
L\approx\operatorname{mean}(valL)-\operatorname{mean}(valR)
$$

取整后作为传感器补偿量，使均匀照明时的 `diff` 接近 0。原程序默认 `L=-3`，实际加在右侧读数上。

在几档光照下复查。若偏差随亮度变化明显，单个固定补偿量只能在部分范围内近似有效，需要检查两只 LDR 的一致性、固定电阻与安装角度。

## 第四步 标定暗光阈值与死区

分别记录正常工作光照和双侧遮挡时的读数，选择能够区分两种情况的 `darkThreshold`。默认 900，仅当两侧原始值均严格大于阈值才停车；停车时串口保留原报告的 `worring R:` 提示。

均匀照明时观察 `diff` 波动，再设置 `thresh`。原值为 13。阈值过小容易频繁转向，过大则需要更明显的光照差异才会响应。调整后分别测试左右光源，避免仅验证正前方。

## 第五步 标定直行与转向

地面测试时先保持光源在正前方，使程序进入直行分支，再调整右轮补偿 `M`。原程序左轮 PWM 为 105，右轮为 119。直行偏向可能还受轮胎摩擦和装配影响，不应只用传感器补偿量修正。

随后测试左右转弯，调整 `speedBase` 和 `speedTurn`，让小车能够转向且内侧轮不过早停滞。默认左转内外轮 PWM 为 35/119，右转为 105/49。每次修改一项参数，并记录结果。
